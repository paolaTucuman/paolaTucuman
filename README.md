# Paola Tucuman

Soy ingeniera financiera orientada a posiciones junior de Análisis de Datos y Business Intelligence, con experiencia adicional en automatización de pruebas.

Mi portafolio reúne proyectos de análisis financiero, visualización de datos, construcción de reportes, machine learning y testing funcional.

## Proyectos destacados

### [Fun Store — Ventas, compras e inventario](https://github.com/paolaTucuman/powerbi-fun-store-sales-purchases-inventory)

#Power BI · Business Intelligence · Análisis de datos

Construí un informe de Power BI para analizar ventas, compras e inventario a partir de múltiples tablas relacionadas. El proyecto incluye indicadores de cantidades, ingresos, desempeño de vendedores y evolución temporal, además del archivo editable y evidencias visuales del reporte.

### [FINANHACK 2024 — Análisis ESG y cartera histórica](https://github.com/paolaTucuman/finanhack-esg-portfolio-analysis)

Python · Refinitiv · Análisis financiero · ESG

Como parte del equipo Full Storm, participé en la extracción de información financiera con Refinitiv, limpieza y análisis de indicadores ESG y presentación de resultados.

El proyecto incluye una comparación histórica de cartera utilizando datos correspondientes al mismo periodo para realizar ajustes y evaluar su comportamiento.

### [OrangeHRM — Functional Testing & web automation](https://github.com/paolaTucuman/QA_Testing_OrangeHRM)

Java · Selenium WebDriver · TestNG · Maven

Desarrollé un proyecto de QA que combina pruebas manuales y automatizadas sobre OrangeHRM.

La automatización cubre autenticación, gestión de empleados y cierre de sesión mediante Page Object Model, datos administrados desde Excel y ejecución en Chrome, Firefox y Edge. El repositorio incluye evidencias de ejecución, resultados de regresión y trazabilidad de hallazgos mediante Jira.
